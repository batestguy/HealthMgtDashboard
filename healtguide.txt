# 🇳🇬 Nigeria Health + Project Management Dashboard
## Specification Document v1.0

---

### 1. Executive Summary

A **mobile-first, single‑page HTML dashboard** that combines:
- **Project management** with complex Excel data import (multiple sheets, cross-references, formulas).
- **Live Nigerian health data** from GRID3 (facility locations) and HDX (aggregated indicators like malaria, immunization).
- **Natural Language Query** (simulated keyword-matching) for conversational data exploration.
- **Interactive quiz** with mixed static + dynamic questions.
- **Multiple chart types** (bar, pie, map, line, scatter).
- **Export/share** functionality.

The dashboard is designed for **internal team use** (project managers, analysts, executives) and delivered as a **self-contained HTML file** hosted on **GitHub Pages** – accessible via a public link from any phone or desktop.

### 3. Data Architecture

#### 3.1 Excel Data (Simulated – Complex)
The dashboard will simulate a **moderately complex** project management dataset with the following sheets:

| Sheet Name | Columns | Purpose |
|------------|---------|---------|
| **Projects** | `ProjectID`, `Name`, `Budget`, `StartDate`, `EndDate`, `Status`, `Owner`, `Region` | Master project list |
| **Tasks** | `TaskID`, `ProjectID` (FK), `Title`, `Assignee`, `Status`, `Priority`, `DueDate`, `Completion%` | Task breakdown per project |
| **Resources** | `ResourceID`, `ProjectID` (FK), `Type` (Person/Equipment), `Name`, `Cost`, `Allocation%` | Resource tracking |
| **Finances** | `ProjectID` (FK), `Month`, `PlannedSpend`, `ActualSpend`, `Variance` | Financial performance |
| **Locations** | `ProjectID` (FK), `State`, `LGA`, `Latitude`, `Longitude` | Geographic mapping |

*All data will be generated synthetically but with realistic distributions (e.g., budgets in ₦/$ millions, states across Nigeria).*

**Upload Mechanism:** SheetJS (XLSX library) reads the file, parses all sheets, and stores data in a client-side JavaScript store.

#### 3.2 Health APIs

| API | Endpoint | Data | Auth | Frequency |
|-----|----------|------|------|-----------|
| **GRID3 Nigeria Health Facilities** | `ArcGIS FeatureServer` | ~51k facilities (name, type, ownership, lat/lng, state) | None | Real-time fetch on tab switch |
| **HDX (Humanitarian Data Exchange)** | `https://data.humdata.org/api/` | Aggregated indicators: malaria prevalence, immunization coverage, maternal mortality, etc. | None (open data) | Cached for 1 hour |

**Fallback:** If an API fails, the dashboard uses pre‑seeded sample data (so the demo never breaks).

### 4. Dashboard Sections & Features

All sections are accessible via a **fixed bottom tab bar** (optimised for thumbs).

#### Tab 1: 📋 Projects
| Feature | Description |
|---------|-------------|
| **Excel Upload** | Drag‑and‑tap area; supports `.xlsx`/`.xls`. Displays filename and row count on success. |
| **Project KPIs** | 4 cards: Total Projects, Total Tasks, Completion Rate (%), Total Budget. |
| **Task Tracker** | List of all tasks with status dots (todo/in‑progress/done), progress %, due date, assignee count. |
| **Project Chart** | Bar chart showing progress % per project (coloured green/yellow/red based on status). |
| **Project Summary** | Dynamic text line e.g., "All projects on track" or "2 projects at risk". |

#### Tab 2: 🏥 Health
| Feature | Description |
|---------|-------------|
| **Health KPIs** | 4 cards: Total Facilities, States Covered, Public Facilities, Private Facilities. |
| **Facility Map** | Leaflet.js map with pin clusters showing facility locations (from GRID3). |
| **Facility Type Chart** | Doughnut chart showing breakdown by type (PHC, General Hospital, Teaching, Clinic, etc.). |
| **Indicator Trends** | Line chart showing HDX data (e.g., immunisation coverage 2015–2025). |
| **Key Indicators** | List view: beds per 10k, doctors per 10k, PHC count, etc. |
| **Refresh Button** | Manually re‑fetch live data. |

#### Tab 3: 🧠 Quiz
| Feature | Description |
|---------|-------------|
| **Batch Progress** | Shows "Question X of Y • Batch Z". |
| **Question Display** | Static trivia (Nigeria health facts) + dynamic questions generated from imported Excel data. |
| **Multiple Choice** | 4 options; clicking disables all buttons and highlights correct/wrong. |
| **Feedback** | Instant correct/wrong message with correct answer shown. |
| **Score Tracker** | Running score displayed as "5/10". |
| **Next / Reset** | Navigate questions or restart the quiz. |

*Dynamic question examples:*  
- "Which project has the highest budget?"  
- "How many tasks are assigned to [Assignee]?"  
- "What is the total planned spend for [Project]?"

#### Tab 4: 💬 Ask (NLQ)
| Feature | Description |
|---------|-------------|
| **Query Input** | Text box with placeholder "Ask me anything about your data…". |
| **Keyword Matching** | Simulated AI that parses keywords like "show", "filter", "top", "budget", "Lagos", "facilities", "tasks". |
| **Response Area** | Displays a summary, updates KPIs, or filters charts based on the query. |
| **Example Chips** | Quick‑tap suggestions: "Show projects in Lagos", "Top 3 tasks", "Facilities by state". |

#### Tab 5: 📤 Export
| Feature | Description |
|---------|-------------|
| **Export as PNG** | Capture the current view (using html2canvas) and download. |
| **Export as PDF** | Generate a PDF report (using jsPDF) including KPIs and a selected chart. |
| **Share Link** | Copy the public GitHub Pages URL to share the dashboard. |

### 7. Natural Language Query (Simulated)

**Algorithm:** Keyword → Action mapping.

| Keyword(s) | Action |
|------------|--------|
| `show`, `list`, `display` | Filter data and refresh charts. |
| `top`, `highest`, `max` | Sort and display top results. |
| `Lagos`, `Kano`, `Abuja` (any state) | Filter projects/facilities by that state. |
| `budget`, `cost`, `spend` | Highlight financial KPIs. |
| `tasks`, `assignee`, `due` | Focus on task tracker. |
| `facilities`, `health`, `hospital` | Switch to Health tab and filter. |

**Response:** The query box updates a summary paragraph and optionally navigates to the relevant tab.

### 8. MCP Integration Strategy (Power BI & Tableau)

Since this is a **static HTML** dashboard hosted on GitHub Pages, live MCP server connections are not possible client‑side. However, we can leverage them for **data preparation**:

1. **Power BI MCP** – Use locally to export your PBIX semantic model as CSV/JSON files. These can be uploaded via the Excel import (or pre‑loaded as sample data).
2. **Tableau MCP** – Use locally to extract data from Tableau workbooks and save as `.hyper` or CSV, then convert to XLSX for import.

**Future Upgrade Path:** If you later deploy a Node.js backend (e.g., on Vercel with serverless functions), you can host the MCP servers there and call them from the dashboard via REST APIs – enabling live Power BI/Tableau data refresh.
